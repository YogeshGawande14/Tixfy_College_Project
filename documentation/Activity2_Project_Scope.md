## 1. Project overview
Tixify is a full-stack movie-ticket booking application inspired by the general user experience of BookMyShow. It is the team's own academic project. The submitted proposal names React, Spring Boot and MySQL, along with HTML5, CSS3, Tailwind CSS, JavaScript, Git and GitHub.

## 2. Problem statement
The submitted proposal states that traditional movie booking systems can experience slow responses, poor real-time seat synchronization and booking conflicts such as double-booking. Tixify aims to provide a lightweight platform for movie discovery, showtime selection, seat selection and booking confirmation.

## 3. Objective
To build a full-stack movie ticket booking application using React, Spring Boot and MySQL; provide an interface for browsing movies, selecting showtimes and picking seats; and develop REST APIs and a structured database to manage bookings and user data.

## 4. Proposed scope
### Included in the submitted proposal
- User registration, login, logout and password management.
- Movie search and movie details including synopsis, cast, language and ratings.
- Filtering by city or genre.
- Theatre, screen, date and showtime selection.
- Interactive seat grid showing available, booked and selected seats.
- Ticket reservation, booking summary including seat cost/taxes, and booking history.
- REST APIs and database-backed management of booking and user data.

### Not explicitly committed in the submitted proposal
Payment gateway integration, external cinema-chain APIs, native mobile apps, AI recommendations and production-scale deployment are not explicitly specified. Treat these as future enhancements unless the guide approves them.

## 5. Five defined modules
1. **User Authentication:** registration, login, logout and password management.
2. **Movie Discovery & Search:** search movies, view details and filter by city or genre.
3. **Theater & Show Management:** select cinemas, screens, dates and show timings.
4. **Interactive Seat Selection:** visual grid of available, booked and selected seats.
5. **Booking & Ticket Confirmation:** ticket reservations, cost/tax summary and booking history.

## 6. Expected outcomes from the submitted proposal
- Full-stack application integrating React, Spring Boot and MySQL.
- Interface to browse movies, check showtimes and book tickets.
- Interactive seat layout that represents seat availability.
- Modular backend for authentication and data management.

These are expected outcomes, not proof of completed implementation.
