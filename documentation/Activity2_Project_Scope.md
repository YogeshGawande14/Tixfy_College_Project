# 🎬 Tixify

> A Full Stack Movie Ticket Booking Platform built using React, Spring Boot, and MySQL.

---

## 📖 Overview

Tixify is a full-stack movie ticket booking application developed as an MCA Capstone Project. The platform enables users to discover movies, browse show schedules, select seats, and manage bookings through a modern and responsive interface.

The project focuses on providing a seamless booking experience while reducing booking conflicts and improving seat availability management.
